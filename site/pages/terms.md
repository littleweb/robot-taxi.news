## 静态版与动态版

GitHub Pages 提供定时导出的静态阅读版，展示导出时间；新闻日期以原文和报告的出刊时间为准。静态版不提供后台、实时搜索、收藏同步、反馈表单、在线 API 或 MCP。动态版的匿名只读接口应遵守返回的缓存与限流说明。
